A home Wi-Fi router's excuse for quitting at a film's finale, written
by a small Python program for the "The Router Confesses" bounty on
make.fun. The router blames the couch: hidden behind it and fed dust
for a year, it quits at the finale and dares the household to act
shocked.

## The line

> Blame the couch: you hid me behind it, fed me dust for a year, then
> acted shocked when I quit at the finale.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the line to `/output/entry.txt` (108 characters,
UTF-8, under the 200-character gate). No network, no dependencies.
